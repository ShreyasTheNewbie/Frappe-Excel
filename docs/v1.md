# Excel View — V1 Release

**Release:** V1.0
**Date:** February 2026
**Status:** Released

---

## Overview

Excel View is a Frappe custom app that adds a full spreadsheet experience to any DocType — globally accessible like List View or Report View. Users can view, edit, and analyze live Frappe data in a grid without leaving the browser.

Built as a monkey-patched custom app — zero modifications to Frappe core.

## Features Shipped in V1

### Grid
- Live HOT grid for **any Frappe DocType** — works globally like List/Report View
- All DocType fields rendered as columns (auto-mapped by fieldtype)
- Inline cell editing with **automatic DB save** (debounced 800ms per document)
- Column sorting, manual column resize
- Copy / paste, undo / redo (HOT built-in)
- Right-click context menu
- Row headers with row numbers

### Formula Engine
- **Formula columns** — add scratch columns (not tied to Frappe fields, never saved to DB)
- Enter any formula: `=SUM`, `=IF`, `=COUNTIF`, `=VLOOKUP`, 500+ functions via HyperFormula
- **Formula bar** — address box (A1 notation) + formula input shows raw formula or value
- **Autofill with relative reference adjustment** — drag fill handle down, row references shift correctly (`=AF1*0.18` → `=AF2*0.18`)
- Formula results displayed in cell; formula string shown in formula bar on selection

### Custom Cell Types
| Frappe Fieldtype | Cell Behavior |
|---|---|
| Link | Autocomplete dropdown — queries `frappe.db.get_list` |
| Select | Listbox dropdown — options from field definition |
| Date / Datetime | Date picker via Frappe's date picker |
| Currency / Float | Formatted with numfmt |
| Check | Checkbox toggle |

### Column Management
- **Hide columns** — single or multi-select (Ctrl+click / Shift+click supported)
- **Show all columns** — restore all hidden columns in one click
- **Add formula column** — prompts for label, adds a scratch column
- **Remove formula column** — removes formula-only columns (Frappe field columns protected)
- Manual implementation (HOT 6.x `hiddenColumns` is PRO-only — implemented via `_master_columns` + `_hidden_col_keys` Set)

### Formatting Toolbar
- Font family selector (7 fonts)
- Font size selector
- Bold, Italic, Underline, Strikethrough
- Text color + Fill/Background color (40-color palette popup)
- Alignment: Left / Center / Right
- Wrap text toggle
- Formatting stored in `format_store` (in-memory), applied via HOT `afterRenderer` hook

### Keyboard Shortcuts
| Shortcut | Action |
|---|---|
| Ctrl+B | Bold |
| Ctrl+I | Italic |
| Ctrl+U | Underline |
| Ctrl+S | Force save |
| Ctrl+F | Search in grid |
| Escape | Cancel edit |

### Export / Import
- Export to `.xlsx` (ExcelJS — lazy loaded at runtime)
- Export to `.csv` (PapaParse)
- Import from `.xlsx`
- Import from `.csv`

### Frappe Integration
- Accessible via view switcher dropdown on any DocType list
- URL: `/app/{doctype}/view/excel`
- Respects Frappe field-level `read_only` — read-only cells shown dimmed
- Respects `can_write` permission — entire grid is read-only for users without write access
- Sidebar filters work (inherited from ListView)
- Pagination: 20 / 100 / 500 / 2500 row selector

### Performance
- Monkey-patched via `app_include_js` — no Frappe core modifications
- Bundle: ~1.4MB (Handsontable + HyperFormula + dependencies)

## Known Limitations in V1

1. **Bundle loads on every page** — not lazy-loaded yet. 1.4MB hits all users even if they never use Excel View.
2. **All fields rendered** — every DocType field becomes a column (Sales Order has 80+ fields). No field picker yet.
3. **Formatting not persisted** — bold/italic/colors reset on page reload (in-memory only).
4. **Formula columns not persisted** — formula columns and their formulas reset on page reload.
5. **No sheet tabs** — single sheet per session, no multi-doctype views.
6. **Autofill formula adjustment** — works for single-column vertical/horizontal fills; multi-range autofill not adjusted.

## Architecture

```
excel_view.bundle.js          ← Single entry point + Frappe monkey-patches
├── utils/field_type_map.js   ← Frappe fieldtype → HOT column config
├── utils/formula_bridge.js   ← HyperFormula ↔ HOT 6.x manual wiring
├── utils/export_manager.js   ← ExcelJS (lazy) + PapaParse
├── cell_types/
│   ├── link_cell.js          ← Link autocomplete editor
│   ├── date_cell.js          ← Date picker editor
│   ├── select_cell.js        ← Select listbox editor
│   ├── currency_cell.js      ← Currency formatter
│   └── check_cell.js         ← Checkbox
└── components/
    ├── excel_board.js        ← Main controller (owns HOT instance)
    ├── formula_bar.js        ← Address box + formula input
    ├── column_manager.js     ← Builds HOT columns from Frappe meta
    ├── data_manager.js       ← Frappe DB sync (queue + debounced flush)
    ├── context_menu.js       ← Right-click menu config
    └── toolbar.js            ← Formatting toolbar
```

## Frappe Monkey-Patches (4 integration points)

All patches in `excel_view.bundle.js` — zero core file modifications:

1. `frappe.router.list_views` + `list_views_route` — URL routing
2. `frappe.views.view_modes` — route validation
3. `frappe.views.ListViewSelect.prototype.setup_views` — view switcher menu item
4. `frappe.views.BaseList.prototype.setup_view_menu` — icon + label in switcher button
