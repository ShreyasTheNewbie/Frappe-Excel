# Excel View — V1 Roadmap (Delivered)

**Version:** 1.0
**Theme:** "Spreadsheet for Any DocType"
**Status:** Shipped — February 2026

---

## Vision

Give Frappe/ERPNext users a full spreadsheet experience for any DocType — accessible globally like List View or Report View — with live database read/write, formula support, and Excel-style formatting. Zero modifications to Frappe core.

---

## Features Delivered

### Grid Engine
- [x] Handsontable 6.2.2 (MIT) grid for any DocType
- [x] Accessible via view switcher — `/app/{doctype}/view/excel`
- [x] All DocType fields auto-mapped to columns by fieldtype
- [x] Inline cell editing — auto-saves to Frappe DB (debounced 800ms)
- [x] Column sorting, manual resize
- [x] Copy/paste, undo/redo (HOT built-in)
- [x] Right-click context menu
- [x] Row headers with row numbers

### Formula Engine
- [x] HyperFormula integration — 500+ Excel-compatible functions
- [x] Formula bar — address box (A1 notation) + formula/value input
- [x] Formula columns — scratch columns not tied to Frappe fields, not saved to DB
- [x] Autofill with relative reference adjustment (`=AF1*0.18` → `=AF2*0.18`)
- [x] Formula results displayed in cell; raw formula shown in formula bar

### Custom Cell Types
- [x] **Link** — autocomplete dropdown via `frappe.db.get_list`
- [x] **Select** — listbox dropdown from field options
- [x] **Date/Datetime** — Frappe date picker
- [x] **Currency/Float** — numfmt formatted display
- [x] **Check** — checkbox toggle

### Column Management
- [x] Hide single or multiple columns (Ctrl+click multi-select)
- [x] Show all columns — restore all hidden columns
- [x] Add formula column — prompt for label, adds scratch column
- [x] Remove formula column — only formula columns removable

### Formatting Toolbar
- [x] Font family + font size selectors
- [x] Bold, Italic, Underline, Strikethrough
- [x] Text color + Fill color (40-color palette popup)
- [x] Alignment: Left / Center / Right
- [x] Wrap text toggle
- [x] Keyboard shortcuts: Ctrl+B/I/U, Ctrl+S, Ctrl+F

### Export / Import
- [x] Export to `.xlsx` (ExcelJS — lazy loaded)
- [x] Export to `.csv` (PapaParse)
- [x] Import from `.xlsx`
- [x] Import from `.csv`

### Frappe Integration
- [x] View switcher integration (no core modifications)
- [x] Respects field `read_only` — dimmed cells
- [x] Respects `can_write` permission
- [x] Sidebar filters inherited from ListView
- [x] Pagination: 20 / 100 / 500 / 2500

| All fields shown — no field picker | V2.0 field picker |

| Formula columns reset on reload | V2.1 saved workbooks |
| No sheet tabs | V3.0 |
| Toolbar wiring incomplete in edge cases | V2.0 |
| Color palette too basic | V2.0 rich palette |
