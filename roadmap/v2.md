## V2.0 — Foundation (Ship First)

### 1. Lazy Loading — Critical

**Problem:** `app_include_js` loads ~1.4MB on every Frappe page regardless of whether the user ever opens Excel View.

**Solution:** Two bundles:
- `excel_view_router.bundle.js` — ~2KB, only registers the view. Loads everywhere.
- `excel_view_deps.bundle.js` — ~1.4MB (HOT + HF + deps). Dynamic import only when Excel View is first opened.

```js
async render() {
    if (!window.Handsontable) {
        await import("/assets/excel_view/dist/js/excel_view_deps.bundle.js");
    }
}
```

**Success metric:** Zero performance cost for users who never use Excel View.

---

### 2. Field Picker / Column Selector

**Problem:** Sales Order has 80+ fields — all rendered at once, grid is unusable.

**Solution:**
- First load → show only `name` + last saved field selection (localStorage)
- If no saved preference → auto-open "Choose Columns" dialog
- "Choose Columns" button always in toolbar

**Dialog:**
- Searchable checklist of all DocType fields
- Fields grouped: Identifiers, Text, Numeric, Date, Link, Select, Check
- Drag to reorder
- Select All / Deselect All per group
- Saved to `localStorage` keyed by `{doctype}:excel_view:columns`

---

### 3. Toolbar — Fully Working

**Current state:** HTML renders, events bound — but formatting applies inconsistently on multi-cell ranges and doesn't survive re-render in all cases.

**Fixes:**
- Bold / Italic / Underline / Strikethrough → apply across full selected range
- Font family + size → apply to range, reflect in cells on next render
- Alignment → HOT `className` update per cell
- Wrap text → HOT `wordWrap` per cell via `cells` callback
- Active state (highlighted button) → correct sync on every selection change
- All ops work for single cell AND multi-cell range

---

### 4. Rich Color Palette

**Replace** flat 40-color grid with a 3-section Excel-style palette:

**Section 1 — Theme Colors**
- 10 columns × 6 tint/shade rows (60 colors total)
- Matches Frappe's CSS color variables where possible

**Section 2 — Standard Colors**
- Fixed row of 10 classic colors (black, white, red, green, blue, etc.)

**Section 3 — Recent Colors**
- Last 10 used, persisted in localStorage per user
- Auto-updates as colors are picked

**Custom Color:**
- `<input type="color">` for native color wheel
- Hex input field for manual entry
- Both text color (A) and fill color (bucket) use this palette

## V2.1 — Saved Workbooks (Replace Saved Report Config)

### 5. Excel Workbook DocType

New Frappe DocType: `Excel Workbook`

| Field | Type | Description |
|---|---|---|
| `title` | Data | User-given name |
| `doctype_name` | Link → DocType | Bound doctype |
| `owner` | Link → User | Creator |
| `is_public` | Check | Shared with all users |
| `columns_config` | JSON | Visible fields, order, widths |
| `formula_columns` | JSON | Formula column defs + per-row formulas |
| `filters` | JSON | Saved filter set |
| `sort_by` | Data | Default sort field |

### 6. Save / Load UI

- "Save View" button in toolbar → name prompt → saves
- "My Workbooks" + "Shared Workbooks" dropdown in toolbar
- On load: restores columns, widths, formula columns with formulas
- Delete workbook option

### 7. Persistent Formula Columns

Saved in `Excel Workbook.formula_columns`:
```json
[{
  "key": "__fml_1__",
  "label": "GST Amount",
  "formulas": { "0": "=AF1*0.18", "1": "=AF2*0.18" }
}]
```
On load: re-create columns, re-apply formulas to fetched rows.

## V2.3 — "Replace Report Builder" Features

### 12. QUERY() Formula — Pull Any DocType Data

```
=QUERY("Sales Order", {filters}, {fields}, {limit})
```
- Returns a 2D array that spills into adjacent cells (like FILTER in Excel)
- Replaces the need to navigate to a DocType list at all
- Cached with 30s TTL, "Refresh" button in formula bar
- Example: `=QUERY("Sales Invoice", [["status","=","Overdue"]], ["name","customer","grand_total"])`

### 13. Parameterized Sheets (Replace Report Filters)

- Define parameters at top of sheet: `{from_date}`, `{to_date}`, `{company}`
- When another user opens the sheet → clean input panel appears first (not raw cells)
- QUERY() formulas reference parameters: `=QUERY("GL Entry", [["posting_date",">=",{from_date}]],...)`
- Saved as part of Workbook doc
- **This replaces Frappe's report filter UI for 90% of use cases**

### 14. Frappe Formula Library (ERP-Native Functions)

Custom HyperFormula function plugins — no other spreadsheet has these:

```
=FRAPPE.GET("Customer", A1, "credit_limit")
=FRAPPE.SUM("Sales Invoice", "grand_total", [["customer","=",A1]])
=FRAPPE.COUNT("Task", [["status","=","Open"],["assigned_to","=",B1]])
=GL_BALANCE(account, company, from_date, to_date)
=STOCK_QTY(item_code, warehouse, as_of_date)
=OUTSTANDING(doctype, docname)
=CREDIT_LIMIT_AVAILABLE(customer)
=ITEM_PRICE(item, price_list, qty, customer)
=LEAVE_BALANCE(employee, leave_type, as_of_date)
```

Each function:
- Makes an API call to Frappe backend
- Results cached per session (no repeated calls for same args)
- Respects permissions — returns `#PERM_DENIED` if no access
- Shows loading state in cell while fetching

**Why this is the moat:** No spreadsheet (Excel, Google Sheets, Odoo) can run live ERP DB queries inside a native formula. This single feature makes Excel View irreplaceable.

### 15. Workflow Actions from Grid

- Right-click row → submenu: **Submit | Approve | Reject | Cancel | Assign To**
- Actions filtered by current workflow state + user's role
- Bulk: select multiple rows → right-click → bulk action → confirmation dialog
- Progress bar for bulk operations ("Submitting 45 of 200...")
- **Replaces navigating to each document individually for batch operations**

### 16. Report Scheduling (Replace Auto Email Report)

- Any saved Workbook can be scheduled: Daily / Weekly / Monthly / Custom CRON
- Auto-refresh data before sending
- Email recipients: specific users or roles
- Attach as: PDF / XLSX / Both
- "Last sent" and "Next send" shown in Workbook metadata
- **Fully replaces Frappe's Auto Email Report feature**

### 17. Saved Views Catalog (Replace Reports List)

- Browse all Workbooks across the system: filterable by DocType / Module / Owner
- Search bar
- My Workbooks / Shared / Recent / Favorites sections
- Accessible from the Frappe top bar or a dedicated "Spreadsheets" page
- **Replaces navigating to Reports module for saved analysis views**
