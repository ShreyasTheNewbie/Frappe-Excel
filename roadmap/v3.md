# Excel View — V3 Roadmap

**Version:** 3.0 → 3.3
**Theme:** "The Spreadsheet That Knows Your Business"
**Status:** Future Planning

---

## Vision for V3

V2 replaced the report builder. V3 makes Excel View the **primary analytics and operations interface** for ERPNext — the thing finance teams, operations managers, and business analysts open every morning instead of a BI tool or a custom dashboard.

Two pillars:
1. **Multi-sheet workbooks** — cross-doctype analysis without developer help
2. **ERP-native intelligence** — features that only work because we're inside the database

---

## V3.0 — Multi-Sheet Workbooks

### 1. Sheet Tabs

- Tab bar at the bottom (like Excel / Google Sheets)
- Each tab = one DocType + filter config, or a formula-only derived sheet
- `+` button → new sheet → pick DocType + filters
- Double-click tab to rename
- Drag to reorder
- Stored in Workbook doc as a `sheets[]` array
- Sheet-level permissions: hide specific tabs from certain roles

### 2. Cross-Sheet Formulas

HyperFormula natively supports multi-sheet. Wire it:
```
=Sheet2.A1
=VLOOKUP(A1, Sheet2.A:B, 2, 0)
=SUMIF(Sheet2.A:A, "Tata Motors", Sheet2.C:C)
```
Each tab registered as a separate HF sheet ID in the same HF instance.
Enables:
- Sales Order sheet + Customer master sheet → combined analysis
- GL sheet + Budget sheet → variance analysis
- Employee sheet + Payroll sheet → headcount cost view

### 3. Derived / Summary Sheet

Special tab type — no DocType, all cells are formulas:
- Pulls data via cross-sheet references from other tabs
- QUERY() formulas, FRAPPE.*() functions, standard formulas all work
- Use cases: P&L consolidation, multi-doctype KPI dashboard, region-wise comparison
- Publish this sheet as a read-only URL for stakeholders

### 4. Named Ranges

- Select any range → assign a name (`GrandTotal`, `CustomerList`, `Q4Revenue`)
- Use in formulas: `=SUM(GrandTotal)` instead of `=SUM(Sheet1.AF1:AF100)`
- Named ranges can also reference QUERY() outputs — the name resolves live
- Workbook-scoped vs sheet-scoped
- Autocomplete in formula bar

### 5. Child Table Row Expansion

- Sales Order row → expand arrow in row header → child rows appear for each line item
- Edit child table cells inline → saves to the child DocType
- Aggregate functions on parent row respect the expanded hierarchy
- Collapse back to summary row
- Works for any DocType with child tables (Items, Accounts, Taxes, etc.)

## V3.1 — Charts & Visuals

### 6. Embedded Charts

- Select a data range → right-click → Insert Chart
- Types: Bar, Line, Pie, Area, Scatter, Combo
- Rendered using Frappe Charts (already in Frappe core)
- Charts float over the sheet — resizable and movable
- Linked to the data range: chart auto-updates when data changes or refreshes
- Stored in Workbook doc with `{type, range, position, size}` config

### 7. Sparklines in Cells

- `=SPARKLINE(A1:A12)` → tiny inline chart inside a single cell
- Types: Line, Bar, Win/Loss
- Shows 12-month trend per row in a summary table
- Color customizable (positive/negative colors)
- Data source: static range or QUERY() result

### 8. Conditional Formatting

- Rules manager dialog: add / edit / delete rules per range
- Rule types:
  - Value comparison (> x, < x, between x and y)
  - Text contains
  - Top/bottom N values
  - Duplicate values
  - Custom formula rule (`=A1>AVERAGE($A:$A)`)
- Formatting: fill color, text color, bold, borders
- Color scales: green-yellow-red gradient across a range (heatmap)
- Data bars: proportional fill within cell
- Rules saved in Workbook doc, applied via `afterRenderer` hook

### 9. KPI Cards (Dashboard-Ready Cells)

- Cell style "KPI" — shows: label, value, trend arrow (▲▼), vs target %
- Rendered like a mini card when the sheet is in "Dashboard Mode"
- Data from FRAPPE.*() functions or plain formulas
- Threshold colors: green if above target, red if below
- Replaces Frappe Dashboard number widgets

### 10. Dashboard Mode

- Toggle any sheet into "Dashboard Mode" — hides grid lines, row/col headers, formula bar
- Shows only content and formatting — clean, presentation-ready
- Print-ready layout with page margins
- URL parameter `?mode=dashboard` for sharing read-only
- Embed code generator for Frappe Portal pages

## V3.2 — Data Power Tools

### 11. Pivot Tables

- Select data range or QUERY() source → Insert Pivot
- Drag-and-drop field builder: Rows / Columns / Values / Filters
- Aggregations: Sum, Count, Average, Max, Min, % of Total, Running Total
- Drill-down: click an aggregate cell → see the underlying records
- Pivot renders as a new derived sheet tab
- Refresh button re-runs the source query
- **Replaces Frappe's Summary Report and most Script Reports**

### 12. Global Filters (Odoo-style)

- A filter panel controlling data across ALL sheets in the workbook simultaneously
- Filter types: Date Range, Company, Cost Center, Project, any Link field
- Set "Fiscal Year = FY 2025-26" once → every sheet's QUERY() updates
- Parameterized sheets (V2.3) wire into global filters automatically
- Stored in Workbook doc

### 13. Data Validation with ERPNext Rules

- Cell-level rules per range:
  - Only numbers / only dates / only from dropdown list
  - Must be a valid DocType record (live DB check): "Must be an existing Customer"
  - Custom formula: `=FRAPPE.COUNT("Item", [["item_code","=",A1]])>0`
- Error tooltip on invalid input (before save)
- Optional: run actual ERPNext field validators via API
- Replaces manual data validation that currently needs a developer

### 14. Variance Analysis Columns (Finance Feature)

- Toolbar button: "Add Variance Columns"
- Picks two numeric columns → auto-generates:
  - `Variance ($)` = Actual - Budget
  - `Variance (%)` = (Actual - Budget) / Budget × 100
  - Conditional formatting applied: positive = green, negative = red
- Pre-built templates: Actual vs Budget, Current vs Prior Period, YTD vs Full Year
- One-click operation that currently takes 15 minutes in Excel

### 15. Import with Field Mapping UI

- Upload `.xlsx` or `.csv`
- Preview first 10 rows
- Drag-and-drop column mapping: uploaded column → Frappe field
- Auto-detect by column header name
- Validate before commit: highlight errors (mandatory missing, invalid link, duplicate)
- Bulk insert or update (upsert by `name` or a selected unique field)
- Progress bar for large imports
- Error report downloadable as CSV

## V3.3 — ERP Intelligence (The Moat)

### 16. Live Cell Binding (LIVE() Formula)

```
=LIVE("Sales Order", "SO-2024-001", "grand_total")
```
- Always shows current DB value, not a snapshot
- Updates via WebSocket when the document changes (no manual refresh)
- Visual indicator: small blue dot on live-bound cells
- Works for any field on any DocType
- Cache with configurable TTL for non-real-time use

### 17. GL & Financial Statement Functions

```
=GL_BALANCE(account, company, from_date, to_date)
=TRIAL_BALANCE(company, from_date, to_date)        // spills full TB
=IS_ACCOUNT(account, company, period)              // Income Statement
=BS_ACCOUNT(account, company, as_of_date)          // Balance Sheet
=BUDGET_VS_ACTUAL(cost_center, account, period)
=DEPRECIATION_VALUE(asset, as_of_date)
```
- A finance user can build a full P&L statement in a sheet without any code
- Data pulled directly from GL Entry, Budget, Asset Depreciation Schedule
- **Replaces all Financial Statement Script Reports**

### 18. Inventory & Operations Functions

```
=STOCK_QTY(item_code, warehouse, as_of_date)
=STOCK_VALUATION(item, warehouse, method)          // FIFO / AVCO
=REORDER_BREACH(item, warehouse)                   // 1 if below reorder
=LANDED_COST(purchase_invoice, item)
=ITEM_PRICE(item, price_list, qty, customer)
```

### 19. HR & Payroll Functions

```
=PAYROLL_COMPONENT(employee, component, period)
=LEAVE_BALANCE(employee, leave_type, as_of_date)
=ATTENDANCE_DAYS(employee, from_date, to_date, status)
=LOAN_OUTSTANDING(loan_name, as_of_date)
```

### 20. Submit / Cancel / Workflow from Grid

- Right-click row → **Submit | Approve | Reject | Cancel | Amend**
- Actions filtered by current workflow state + user's role
- Bulk: select rows → right-click → bulk action → confirmation + progress bar
- "Status" column type: shows workflow state, click to trigger valid transitions
- **Replaces navigating to each document for batch approvals**

### 21. Audit Trail per Cell

- Right-click any cell → "Show History"
- Pulls from Frappe's Version doctype
- Shows: who changed, from what value, to what value, when
- Timeline view with diffs highlighted
- Filter by date range or user
- **Replaces asking "who changed this?" across the organization**

### 22. Scheduled Snapshots & Version History

- Schedule a workbook to take a data snapshot (daily / weekly / month-end)
- Snapshots stored as a Workbook Version (separate DocType)
- "Diff View": compare current vs any past snapshot — changed cells highlighted
- Restore to any previous snapshot
- Associate snapshots with ERPNext periods (link to Period Closing Voucher)

### 23. Workbook Templates Library

Pre-built workbooks auto-wired to ERPNext DocTypes:

| Template | Replaces |
|---|---|
| P&L Statement | GL Summary Report |
| Balance Sheet | Balance Sheet Report |
| AR Aging | Accounts Receivable Summary |
| AP Aging | Accounts Payable Summary |
| Inventory Aging | Stock Ageing Report |
| Cash Flow | Cash Flow Statement |
| Payroll Summary | Payroll Summary Report |
| GST GSTR-1 | GSTR-1 Script Report |
| Sales Performance | Sales Analytics Report |
| Purchase Analysis | Purchase Analytics Report |

Each template is installable from a template catalog with one click.

### 24. Embed Workbook in DocType Forms

- A "Spreadsheet" section insertable in any DocType via Customize Form
- Shows a mini Excel View filtered to records related to this document
- Example: Customer form → inline Sales Orders sheet for that customer
- Read-only or editable based on form permissions
- No navigation required — data in context where user already is

### 25. Scenario Manager (Finance Power Feature)

- Save named scenarios: "Base Case", "Optimistic", "Stress Test"
- Each scenario = a set of override values for specific input cells
- Switch scenarios → sheet recalculates with scenario values
- Compare two scenarios side-by-side in adjacent columns
- Output: auto-generated scenario comparison table
- **Replaces manually maintaining 3 copies of a budget spreadsheet**
